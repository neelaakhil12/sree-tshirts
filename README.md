# Wear Mingle - Modern E-Commerce Platform

A premium, Myntra-inspired e-commerce website for **Wear Mingle (Sree Sai Apparels)**. Built with a focus on high-performance, clean aesthetics, and smooth animations.

## 🚀 Features
- **Modern Homepage**: Animated hero, category cards, and trending items.
- **Dynamic Products**: 42+ initial T-shirt designs for Men, Women, and Kids.
- **Advanced Filtering**: Filter by category, size, price, and smart search.
- **Premium Detail Page**: Size selection, wishlist, and shipping highlights.
- **Interactive Cart**: Shopping bag drawer with real-time price calculations.
- **Admin Portal**: Secure dashboard for product management (CRUD operations).
- **Responsive Design**: Optimized for Mobile, Tablet, and Desktop.
- **Floating WhatsApp**: Direct customer support button.

## 🛠️ Technology Stack
- **Frontend**: React.js, Tailwind CSS, Vite.
- **Animations**: AOS (Animate On Scroll), Framer Motion.
- **Icons**: Lucide React.
- **State Management**: React Context API (Cart System).
- **Routing**: React Router DOM.

## 📦 Getting Started
1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Build for production: `npm run build`
